# takepause.in

First draft of the website for **Take A Pause** — a small-batch bakery by
Rutvi Dharsandhiya. *A little peace, plated.*

A single scrolling page. Every section is built around one idea from the brand:
that the good things are worth slowing down for, so the page never rushes you.

## Running it

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static output in dist/
npm run preview  # serve the build
```

`dist/` is plain static files — Netlify, Vercel, Cloudflare Pages or any bucket
will host it as-is.

## What's on the page

| Section | The scroll moment |
|---|---|
| Preloader | Two held seconds on the mark before the curtain lifts |
| Hero | Title lines rise out of their own baseline; the bloom and petals drift on parallax |
| Ribbon | Brand lines that drift constantly and lean into your scroll direction |
| Our Story | Arched image travelling slower than the page |
| Menu | An index, not a card grid — the hovered row raises its photo under your cursor |
| Custom Cakes | The section pins and the four steps travel sideways as you scroll |
| Occasions | Pills blur in on a stagger |
| Why | The paragraph lights word by word, pacing your reading |
| Gallery | Three columns drifting at three different speeds |
| Kind Words | Quotes crossfading on a six-second dwell |
| Contact | Details, hours, and the WhatsApp CTA |

Every animation is gated behind `prefers-reduced-motion` — with it on, the
smooth scroll, the parallax, the petals and the preloader all step aside.

## Editing content

**All copy lives in one file: `src/content/site.ts`.** Prices, menu items,
testimonials, hours, links — change them there and they update everywhere. No
copy is hardcoded in a component.

## Brand assets

### The logo

`src/components/Logo.tsx` currently *draws* the lockup — the bloom as vector,
the wordmark in Kaushan Script, the tagline letterspaced beneath — so it stays
crisp at any size and animates cleanly.

To use the original artwork instead, drop it at `public/brand/logo.png`. The
component picks it up automatically and falls back to the drawn version if it
isn't there. No code change needed. See `public/brand/README.md`.

Still worth adding when they exist: `public/brand/og.png` (1200×630 share card)
and `public/brand/apple-touch-icon.png` (180×180).

### The photography

Everything in `public/images/` is a **placeholder** — soft watercolour washes in
the brand palette, generated by `scripts/make-placeholders.mjs`. They hold the
layout and the mood; they are not photographs.

Replace them by dropping real images in and pointing at them in
`src/content/site.ts`. Portrait crops around 4:5 fit the layout best.

### Type

Cormorant Garamond (display), Jost (interface), Kaushan Script (the accent
word, echoing the mark). All three are **self-hosted** in `public/fonts/` — no
third-party request, no layout shift from a slow CDN. Regenerate with:

```bash
node scripts/fetch-fonts.mjs
```

### Palette

Taken straight off the logo, defined as tokens in `src/index.css`:

| Token | | Where it comes from |
|---|---|---|
| `cream` `#fbf6ea` | the paper the mark sits on |
| `shell` `#f4ecdc` | a half-step deeper, for alternating sections |
| `ink` `#1e1a17` | the brush wordmark |
| `blush` `#e5a091` | the flower |
| `sage` `#a2b393` | the stem and leaves |
